# 쇼핑몰 매니저 Windows 배포

승인된 Discord 계정으로 사용하는 알로요가·웍스아웃 쇼핑 관리 앱의 공개 배포 저장소입니다.
이 저장소에는 설치파일과 서명된 자동 업데이트 정보만 게시합니다. 프로그램 소스코드와 사용자 데이터는 포함하지 않습니다.

첫 Windows 릴리즈는 아직 게시하지 않았습니다.

첫 릴리즈 이후 설치파일: https://github.com/ddin-ddin/alo-manager-releases/releases/latest/download/alo-manager-installer.exe

설치된 앱은 1분마다 새 버전을 확인하며, 앱 안에서 다운로드와 설치를 선택할 수 있습니다.
업데이트 후 다시 실행하면 Discord 로그인이 필요합니다.

무단 분석·역공학·구현 복원·복제 지원은 허용하지 않습니다. 승인된 유지보수와 제삼자 라이선스의 권리는 보존됩니다.
